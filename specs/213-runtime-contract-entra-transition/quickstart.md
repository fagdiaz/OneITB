# Quickstart: Spec 213

1. Ejecutar el preflight contra el backend ya iniciado.
2. Si falla, detener solo el PID antiguo y arrancar el corte esperado con lifecycle
   controlado según `RUNBOOK_DEV.md`.
3. Probar éxito, cancelación y recarga del callback en Firefox.
4. Confirmar un intercambio GraphQL, una sesión y ausencia de flash de Login.
