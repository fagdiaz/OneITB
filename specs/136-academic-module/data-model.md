# Data Model: Academic Module

## AcademicResource

Represents a study material item associated with a subject.

| Field | Type | Rules |
|---|---|---|
| Id | Guid | Generated by application; primary key |
| SubjectId | int | Required FK to active `Subject` |
| UploaderId | Guid | Required FK to active `User` |
| Title | string | Required, trimmed, 3-200 chars |
| Description | string? | Optional, max 1000 chars |
| FileUrl | string? | Optional, max 500 chars, must start with `/uploads/` when present |
| ExternalUrl | string? | Optional, max 500 chars, must be absolute `http` or `https` when present |
| ResourceType | string | Required: `File`, `Link`, `Mixed` |
| CreatedAt | DateTime | UTC timestamp |
| UpdatedAt | DateTime? | UTC timestamp when changed/deactivated |
| IsActive | bool | Defaults true; false hides from normal resource lists |

### Relationships

- `AcademicResource.SubjectId` -> `Subject.Id`, `DeleteBehavior.Restrict`
- `AcademicResource.UploaderId` -> `User.Id`, `DeleteBehavior.Restrict`

### Validation

- At least one of `FileUrl` or `ExternalUrl` is required.
- Students cannot create or deactivate resources.
- New resources require an active subject.

## AcademicProgress

Represents the current academic state for a student and subject.

| Field | Type | Rules |
|---|---|---|
| Id | Guid | Generated by application; primary key |
| UserId | Guid | Required FK to student `User` |
| SubjectId | int | Required FK to active `Subject` |
| AssignedById | Guid | Required FK to teacher/admin `User` |
| Score | decimal? | Optional; when present, 0-10 with two decimal precision |
| Status | enum/string | Required: `Regular`, `Approved`, `Free`, `InProgress` |
| Notes | string? | Optional, max 1000 chars |
| UpdatedAt | DateTime | UTC timestamp |

### Relationships

- `AcademicProgress.UserId` -> `User.Id`, `DeleteBehavior.Restrict`
- `AcademicProgress.SubjectId` -> `Subject.Id`, `DeleteBehavior.Restrict`
- `AcademicProgress.AssignedById` -> `User.Id`, `DeleteBehavior.Restrict`

### Validation

- Unique record by `(UserId, SubjectId)`.
- Assigned user must be `Profesor` or `Administrador`.
- Students can read only their own records.
- Administrators can read any record.
- Teachers can assign/update records; administrators can assign/update records.

## AcademicProgressStatus

Allowed values:

- `InProgress`
- `Regular`
- `Approved`
- `Free`

## Query Shapes

- Subject resources include `Subject`, `Subject.Career` and `Uploader`.
- Progress records include `User`, `Subject`, `Subject.Career` and `AssignedBy`.
- Lists are ordered by most recent update/create date.
