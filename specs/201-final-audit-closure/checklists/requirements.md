# Requirements Quality Checklist

- [x] Findings are linked to concrete controls or explicit gates.
- [x] Authorization rules identify actor, target and scope.
- [x] Public error behavior is specified.
- [x] Cancellation and bounded execution are required.
- [x] Database migration impact is explicit.
- [x] External/manual gates cannot be marked complete from static evidence.
- [x] Git side effects are excluded.
- [x] Definition of Done includes build, test, EF and documentation checks.
- [x] Upload redesign is not disguised as a low-risk quick fix.
- [x] Professor career scope is documented as an equivalent freeze-safe policy, not a full ProfessorSubject model.
