# Quickstart: Media Embed Console Contract

1. Start the backend and frontend through the runbook when the local SQL/HTTPS environment is available.
2. Open a feed item containing a YouTube URL.
3. Confirm the card initially shows a local preview with a play button and no iframe network/script execution.
4. Click the play button.
5. Confirm the iframe loads and the video can be played.
6. Treat any provider cookie/storage or Firefox privacy warning after the click as third-party residual behavior and record it in evidence.

Build check:

```powershell
cd FrontEnd/OneItb-FE
npm.cmd run build
```
