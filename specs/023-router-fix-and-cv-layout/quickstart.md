# Quickstart Guide: Router Fix & CV Layout (023)

## Local Run Instructions
1. Move to the frontend directory:
   ```bash
   cd FrontEnd/OneItb-FE
   ```
2. Build the application:
   ```bash
   npm run build
   ```
3. Run in development mode:
   ```bash
   npm run dev
   ```

## Routes Reference
- `/`: Welcome Landing Page.
- `/login`: User Authentication Form.
- `/register`: User Enrollment Form.
- `/feed`: Activity wall / main dashboard.
- `/profile`: Dynamic user CV details and edit fields form.
