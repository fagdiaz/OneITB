# Quickstart

1. Aplicar `AddFileUrlToComment`.
2. Iniciar backend y frontend.
3. Publicar una imagen, un PDF y un texto con YouTube.
4. Verificar imagen inline, tarjeta de PDF y reproductor.
5. Crear un comentario y una respuesta con archivos.
6. Recargar y confirmar persistencia.
7. Probar una URL de otro host parecida a YouTube y confirmar que no se embebe.

```powershell
dotnet build "API Graphql/OneITB/GraphQL.csproj" -c Release
npm.cmd run build
```
