# Data Model: Employer Onboarding

## EmployerRequest

| Field | Constraint |
|---|---|
| Id | GUID, generated by application |
| CompanyName | nvarchar(160), required |
| ContactName | nvarchar(160), required |
| Email | varchar(256), normalized, required |
| Phone | varchar(32), required |
| TaxId | char(11), checksum-valid, required |
| Comments | nvarchar(1500), optional |
| Status | varchar(20), Pending/Approved/Rejected |
| RejectionReason | nvarchar(500), optional |
| CreatedAt | datetime2 |
| ProcessedAt | datetime2, optional |
| ProcessedByAdminId | FK User, optional, Restrict |
| ProvisionedUserId | FK User, optional, Restrict |
| PrivacyConsentAt | datetime2 |
| EmailDeliveryStatus | varchar(20) |
| LastEmailAttemptAt | datetime2, optional |
| EmailDeliveryAttempts | int |
| RowVersion | rowversion |

Filtered unique indexes cover email and TaxId where status is Pending or Approved.

## EmployerOnboardingOutboxMessage

| Field | Constraint |
|---|---|
| Id | GUID |
| EmployerRequestId | unique FK, Restrict |
| Status | Pending/Processing/Delivered/Failed |
| CreatedAt/NextAttemptAt | datetime2 |
| LeaseExpiresAt/ProcessedAt | datetime2, optional |
| Attempts | int |
| LastErrorCode | varchar(80), optional |
| RowVersion | rowversion |

No recipient, token, body, password or secret is stored in this table.

## Account change

`MagicLinkEnabled` is explicit. The database credential invariant becomes:

```text
PasswordHash exists OR complete Entra identity exists OR MagicLinkEnabled = true
```

Application authorization additionally restricts Magic Link to active `Empleador`.
