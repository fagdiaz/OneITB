# Data Model: Realtime Private Messaging

## Message

Represents one immutable private text message.

| Field | Type | Rules |
|---|---|---|
| `Id` | `Guid` | Primary key, generated by application |
| `SenderId` | `Guid` | Required FK to active `User`; cannot equal `ReceiverId` |
| `ReceiverId` | `Guid` | Required FK to active `User`; cannot equal `SenderId` |
| `Content` | `string` | Required, trimmed, 1-2,000 characters |
| `SentAt` | `DateTime` | Required UTC timestamp |
| `IsRead` | `bool` | Defaults to `false`; only receiver-side viewing sets `true` |
| `Sender` | `User` | Required navigation |
| `Receiver` | `User` | Required navigation |

## User navigation additions

- `SentMessages`: messages where the user is `Sender`.
- `ReceivedMessages`: messages where the user is `Receiver`.

## Relationships

- `Message.SenderId -> User.Id`: many-to-one, `DeleteBehavior.Restrict`.
- `Message.ReceiverId -> User.Id`: many-to-one, `DeleteBehavior.Restrict`.

No cascade path is allowed. Every FK property is explicit, so no shadow column is inferred.

## Indexes

- `(SenderId, ReceiverId, SentAt, Id)` for directional history.
- `(ReceiverId, SenderId, SentAt, Id)` for reverse-direction history.
- `(ReceiverId, IsRead, SentAt)` for unread counts and read updates.

## Derived models

### MessagingContact

Read-only projection:

- `UserId`
- `FirstName`
- `LastName`
- `Role`
- `LastMessageAt` nullable
- `UnreadCount`

The projection excludes the authenticated user and inactive accounts. Correlated database
subqueries compute last activity and unread count without per-contact resolver calls.

### Conversation

Not persisted as a separate entity. A conversation is the ordered union of messages where:

```text
(SenderId = currentUser AND ReceiverId = otherUser)
OR
(SenderId = otherUser AND ReceiverId = currentUser)
```

## State transitions

```text
Created (IsRead = false)
  -> Viewed by receiver (IsRead = true)
```

Messages are not edited or deleted in this increment.
