# Data Model: Jobs Module and Enterprise Seeder

## JobOffer

| Field | Type | Rules |
|---|---|---|
| `Id` | `Guid` | Primary key, value generated by application |
| `Title` | `string` | Required, max 180 |
| `Company` | `string` | Required, max 160 |
| `Description` | `string` | Required, max 2000 |
| `Location` | `string` | Required, max 160 |
| `IsActive` | `bool` | Required, default true |
| `CreatedAt` | `DateTime` | Required, UTC |
| `EmployerId` | `Guid` | Required FK to `User` |
| `Employer` | `User` | Navigation |

## Relationships

- `JobOffer.EmployerId -> Users.Id`: required, `DeleteBehavior.Restrict`.
- `User.JobOffers`: collection navigation.

## Indexes

- `EmployerId`
- `CreatedAt`
- `(IsActive, CreatedAt)`

## Seeder graph

- Careers: `ADS`, `CDIA`.
- Subjects: 3 per career.
- Users: 2 admins, 4 professors, 4 students, 2 graduates, 2 employers.
- Inquiries: 2 per subject for every non-admin, non-employer user in their career.
- Job offers: 2 per employer.
- Comments/replies/reactions/messages/notifications: deterministic FK-safe generated rows.
