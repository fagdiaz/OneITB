# 1. Presentacion general del proyecto

## 1.1 Organizacion

OneITB23 es desarrollado como proyecto academico full-stack para el Instituto Tecnologico Beltran. El equipo cubre desarrollo web, persistencia, seguridad, experiencia de usuario y documentacion mediante un flujo iterativo basado en especificaciones.

## 1.2 Problema

La informacion academica y la comunicacion entre estudiantes, docentes y egresados se distribuyen entre canales sin una trazabilidad comun. Esto dificulta encontrar respuestas por materia, compartir recursos y sostener conversaciones contextualizadas.

## 1.3 Objetivo

Construir una red social educativa que permita:

- Organizar usuarios por carreras y materias.
- Crear publicaciones, comentarios, respuestas y reacciones.
- Compartir archivos educativos y multimedia.
- Mantener perfiles academicos y profesionales.
- Comunicarse mediante chat privado en tiempo real.
- Moderar contenido y administrar la estructura institucional.
- Proveer acceso móvil nativo continuo y en tiempo real.

## 1.4 Stack

- Backend: .NET 8, HotChocolate GraphQL y EF Core 8.
- Persistencia: SQL Server (Migrando a Azure SQL Free Tier).
- Frontend Web: React 18, Apollo Client, Vite 8 y Tailwind CSS 4.
- Frontend Móvil: React Native y Expo.
- Despliegue e Infraestructura: Docker, Azure App Service F1, GitHub Actions y Cloudinary.
