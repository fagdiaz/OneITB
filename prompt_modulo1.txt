# [TAREA 1: AUDITORÍA DE CÓDIGO FRONTEND]
Utiliza tus herramientas para escanear la carpeta del frontend (`FrontEnd/OneItb-FE/src/`), enfocándote en:
1. Configuración de Apollo Client y flujos de Autenticación/Logout.
2. Componentes que rendericen contenido rico o Markdown (ej. publicaciones, comentarios).
3. Manejo de estado global y Error Boundaries.

Busca implacablemente estas vulnerabilidades (cita archivo y línea exacta si las encuentras):
- **Fuga de Caché (Cross-Account Data Leak):** Verifica el flujo de Logout. ¿Se invoca explícitamente `client.clearStore()` o `client.resetStore()` en Apollo? Si la caché no se limpia al cerrar sesión, un usuario que se loguee en la misma pestaña verá datos del usuario anterior.
- **Vulnerabilidad XSS (Cross-Site Scripting):** Busca cualquier uso de `dangerouslySetInnerHTML`. Verifica si el contenido de los usuarios (Markdown o HTML) pasa por una librería de sanitización estricta (como DOMPurify) antes de renderizarse.
- **Fallas en Error Boundaries:** Revisa si el `GlobalErrorBoundary` atrapa correctamente errores de renderizado en el árbol principal.
